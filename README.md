# 雀魂对战记录爬虫

## 项目描述
这是一个用于爬取雀魂游戏对战记录的Python脚本。该脚本可以自动获取指定玩家的对战数据，并将其保存为CSV格式，方便后续分析。

## 功能特点
- 自动获取玩家对战记录
- 记录对战时间、玩家昵称、得分和回放链接
- 数据以CSV格式保存，便于分析和处理
- 自动滚动加载更多对战记录

## 环境要求
- Python 3.x
- 依赖库：
  - requests
  - csv
  - DrissionPage
  - datetime

## 安装方法
1. 克隆仓库到本地
   ```
   git clone https://github.com/你的用户名/code.git
   cd code
   ```

2. 安装依赖
   ```
   pip install requests DrissionPage
   ```

## 使用方法
1. 运行脚本
   ```
   python code.py
   ```

2. 脚本会自动打开浏览器，访问指定玩家的对战记录页面
3. 数据会自动保存到同目录下的"模版.csv"文件中

## 数据格式
爬取的数据包含以下字段：
- 名字：玩家昵称
- 时间：对战开始时间
- 点数：玩家得分
- 链接：对战回放链接

## 注意事项
- 脚本会在页面五秒内没有新数据加载时自动停止
- 目前代码中的玩家ID是固定的，如需修改请更改脚本中的URL
